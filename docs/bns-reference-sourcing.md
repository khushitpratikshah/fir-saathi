# BNS Reference Sourcing

FIR Saathi’s BNS feature is a **prototype review aid**, not a charge-selection, FIR-registration, or legal-advice system. The catalogue proposed for the usability update must use the official text of the Bharatiya Nyaya Sanhita, 2023 as its primary source and retain a visible source link plus the date each entry was reviewed.

The Ministry of Home Affairs hosts the gazette text of the Bharatiya Nyaya Sanhita, 2023 (Act No. 45 of 2023). The document was opened and visually confirmed on 23 August 2026 as the authoritative baseline for future catalogue entries.[1]

| Catalogue field | Required handling |
|---|---|
| Section and heading | Copy from the reviewed official text; do not ask the model to invent or normalize a section. |
| Source | Store the official URL and a reviewed-on date with every entry. |
| AI eligibility | Only surface an entry when each displayed evidence quote appears contiguously in the citizen’s source statement. |
| Uncertainty | Show unconfirmed factors separately and default to **Officer review required** if the source does not support an entry. |
| Human decision | A constable remains responsible for every legal or procedural decision; the UI must state that no FIR is registered by the feature. |

## Reference

[1] [Ministry of Home Affairs, *The Bharatiya Nyaya Sanhita, 2023* (official gazette PDF)](https://www.mha.gov.in/sites/default/files/250883_english_01042024.pdf)
